# 规则调整 03：没有驾照不能建档，取消独立手工建档

日期：10/17/2026。用户明确纠正：“手工建档也必须要驾照，也就是说没有所谓的手工建档啊，不能没有驾照的情况下建的。”本规则优先于旧清单与原型中的独立手工建档、先建空档案再补驾照等描述。

## 确定规则

1. **上传驾照是所有新建客户的必要前置条件。**按已有正面规则，先成功上传驾照正面图片并保留其文件关联，不能仅凭姓名、驾照号码或其他手填字段创建客户。
2. 取消独立“手工建档”入口。单个与批量共用 C12 上传流程，允许选择 1 张或多张；不再另做不带驾照的新建抽屉。
3. 上传成功不等于识别成功、人工确认或建档成功。上传完成前不产生正式客户；识别结果仍需人工核对。
4. OCR 失败不意味着无法继续，也不能绕过驾照：工作人员只能对着**已经上传的原图**人工转录并确认，再进入统一提交。界面用“人工转录”，避免“手工录入”被理解为独立无证件建档。
5. 提交新建前须仍有成功上传且可关联的驾照文件；仅暂存字段、图片上传失败、文件已不可用或未完成人工核对，不得显示建档成功。没有驾照时只允许停留在上传/待处理阶段。
6. 重复处理中“作为不同客户另建”也必须满足上传驾照前提；仅关联已有仍不覆盖已有字段/图片，不自动合并。字段差异选择仍先暂存，批次提交成功后才写正式档案。
7. 其他资料可以之后补充，但不能再把驾照图片归入可在创建后才补的资料。反面可后补；驾照地址与当前住址保持独立。
8. 操作人仍按上传、识别发起、人工确认、成功字段写入分别记录；无客户负责人，已有申请定稿不受影响。
9. “已创建”必须同时满足客户记录保存成功、驾照正面成功关联到新客户；不能把无图片关联的空档案当作建档成功。部分写入或结果未知先核实，不盲目重复创建。
10. OCR 失败后人工转录的数据注明人工来源及操作人，不能把转录完成改写成“AI 识别成功”。转录和确认可由同一员工完成，不据此增设人员分配要求。

## 不是本次新增要求

- 不自动推断驾照真假、是否满足支付平台审核、有效期是否合格；这些不能从“必须有驾照”自行扩展成新的自动审核规则。
- 本轮仅约束建档前置条件，不擅自变更后续图片替换/移除权限或删除客户政策。
- 不重定完整个人资料的全部必填项；之前“姓名至少一项即可建档”的快建草案已作废，不能拿它替代证件前置。
