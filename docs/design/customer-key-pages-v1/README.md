## 设计边界

- 沿用当前项目白底、深蓝主色、灰边框、约 10px 圆角、中文管理表格风格；依据实际样式与组件源码，不宣称已截图复刻当前运行页面。
- 客户已完成可以与第二个网关在办同时存在。
- AI 材料检查只是参考，不是申请门槛。
- 仅识别驾照正面，反面后续上传；驾照地址不等于当前住址。
- 重复客户由人判断，材料直接替换，不引入材料版本或后续维护业务。
- 图中的证件为明显标注 DEMO 的非真实示意，不含真实客户证件。
- 本轮不设计支付接入、付款测试、客户门户或表格导入。
