- `O-C16-delete-execution-v1.png`：删除步骤部分完成、失败、结果未知与按规则保留并存；未提前宣称删除完成。

- `O-C10-remove-failure-v1.png`：移除失败，原文件和原归因保持有效。
- `O-C04-save-failure-v1.png`：保存失败后输入保留，正式档案原值与归因不变。

## 业务边界

- 全部为 DEMO 示例；日期按美国格式。
- 准备资料阶段不显示客户负责人；涉及人员仅为真实操作归因或具体申请负责人。
- 失败、取消、格式不支持或结果未知均不冒充成功，也不抢占最后成功操作人。
- 当前资料的替换、移除失败不影响已有申请定稿。
- 客户删除不默认删除域名、商业邮箱或原始邮件；实际网站删除与内部记录删除不冒充原子操作。
- O-C15 只证明管理员示例可执行，不决定其他员工或申请负责人的删除权限。
