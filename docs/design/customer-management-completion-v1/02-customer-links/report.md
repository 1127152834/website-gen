# 客户管理补齐原型：网站、审核与网关申请

日期：10/17/2026  
状态：**12 张静态候选均待用户确认；不表示应用代码、权限、远端平台或真实流程已经实现。**

## 交付

- `C07-website-mail-v1.png`：网站、商业邮箱与公开信息来源。
- `C08-review-v1.png`：材料审核混合结果，明确 AI 仅供参考。
- `C09-applications-active-v1.png`：客户已完成且存在 PayPal 在办申请。
- `C09-applications-idle-v1.png`：客户已完成、无在办、可开始后续申请。
- `O-C11-link-site-v1.png`：把当前站点更换为未占用站点。
- `O-C12-link-mail-v1.png`：把当前邮箱更换为未占用邮箱。
- `O-C13-unlink-confirm-v1.png`：只解除关联，不删除远端资源。
- `O-C14-public-info-v1.png`：档案值与网站读取值对照。
- `O-G01-review-scope-v1.png`：增量审核范围及不可移除的受影响关联项。
- `O-G02-review-running-v1.png`：逐项完成、执行中、失败与取消。
- `O-G03-finding-detail-v1.png`：带 DEMO 证据的参考意见详情。
- `O-G04-start-application-v1.png`：内部申请记录、申请负责人和不可变资料定稿。

每张最终 PNG 的尺寸、字节数和 SHA-256 在 `manifest.json`；生成来源和提示词摘要在 `prompts.json`。`prompts.json` 的 `prompt` 字段是便于审阅的**提示词摘要，不冒充逐字完整工具调用文本**；原始生成文件路径和每次关键修复均已记录。修复前的 C07/C08/C09、O-C11/O-C12/O-C14、O-G01/O-G02 版本保存在 `before-fix/`。

## 业务核验

- 客户完成状态与当前申请状态始终分开；后续申请不覆盖已有有效获批，误判获批纠正后重新计算客户状态。
- 有在办申请时没有第二个“开始申请”；无在办分支才显示开始入口。
- O-G04 只创建内部申请记录和不可变定稿，不代表支付平台收件；提交时重查单在办冲突。
- 材料审核未做、失败或发现问题都不是硬闸门；运行失败不等于材料不合格。
- 增量审核保留受影响关联项；O-G02 的混合运行样例不是 O-G01 当前勾选状态的一键逐像素后继，而是同一能力的另一独立示例。
- 站点/邮箱更换不会让一个客户同时关联两个当前资源；占用候选不可选。
- 企业地址统一为 `260 Demo Blvd, Austin, TX 78702`；公开信息品牌允许不同于法定名称。
- C09 的“补充证明”是**待用户确认的落点建议**：仍属客户当前材料，不锁定某次申请、不等于已发送，也不恢复独立材料页。
