# Design System: 业务工作台 · 一期客户管理

这是现有内部业务系统的忠实原型迁移，不是视觉重设计。所有界面使用简体中文，个人/企业/域名保留提供的英文 DEMO 值。页面行为服从 BUSINESS.md；视觉服从此文件与逐屏规格。不要把任何 DESIGN 技能的默认艺术化、永久动画、巨型圆角、三卡片禁令套用到已确认的业务布局。

## 1. Visual Theme & Atmosphere

克制、清晰、专业的日常业务工作台。Density 7/10，Variance 2/10，Motion 1/10。白底、深墨蓝层级、灰蓝标签、细分隔线、紧凑可扫描表格。不是市场宣传页：没有 Hero、装饰照片、统计大屏、虚构 KPI、环形进度、推荐下一步、营销标语。

参考画板约 1488×1056。桌面优先。客户列表采用左导航约248px、左客户列表约536px、右速览余宽。档案采用同宽左导航和填满余宽的内容区。正文两栏、表格和侧抽屉按内容使用，不擅自卡片化或改成悬浮岛布局。

## 2. Color Palette & Roles

- Canvas / Surface White `#FFFFFF`：页面、表格与抽屉基础，不混用暖灰。
- Heading Ink Navy `#101B46`：标题、选中导航、强层级文字，不用纯黑。
- Body Navy `#17264D`：普通字段值、表格正文。
- Muted Slate Blue `#62769A`：未选导航、图标、辅助说明、字段标签；不要用艳蓝冒充可点击内容。
- Pale Blue Border `#DFE6F1`：1px 边界与表格分隔线。
- Active Tint `#EDF3FD`：选中客户、激活导航浅背景。
- Primary Navy `#14264F`：实心主按钮，白字；不是亮蓝或绿色主按钮。
- Action Blue `#246FC5`：唯一交互强调色，复制、查看、链接与焦点边框；禁止紫色/霓虹/渐变。
- Success `#07984A` / pale green `#E6F7EE`：已完成、已获批、上传成功。
- Attention `#9A4A0C` / amber dot `#E9A008` / pale amber `#FFF6E7`：待补件、疑似重复、需要人工知悉。不是确定失败。
- Failure `#CC3030` / pale red `#FFF1F1`：确定上传/保存/执行失败及有条件启用的删除危险动作。
- Unknown/Disabled `#8290AC` / pale neutral `#F1F4F8`：未核对、未执行、未知、未满足确认条件。语义色不用于品牌装饰。
- Overlay Scrim：深墨蓝约45%透明度，只在覆盖层后遮罩，底页数据仍必须正确。

## 3. Typography Rules

使用 Noto Sans SC（简体中文）搭配 Geist（拉丁），可降级为 Microsoft YaHei/Arial/sans-serif。软件界面禁止衬线体。不要换成营销式展示字体。

桌面模块标题32px/700，客户姓名32px/700；区块标题22–24px/600；普通正文16px/400–500；标签14–16px；辅助文字13–14px。抽屉标题28–32px，副标题16px。表头16px/600。行高1.4–1.5，时间与数字等宽对齐，不因字重放大所有数据。日期必须MM/DD/YYYY；日期输入占位同格式。不得出现YYYY-MM-DD界面日期。

## 4. Component Stylings

- 按钮：高度40–44px、6px圆角，主按钮深藏蓝实心；次按钮白底细描边；文字操作亮蓝。取消始终可辨认；未勾选必要确认时提交按钮浅灰蓝且真正表达禁用，不只是改文字。
- 表格：细浅灰蓝横线、浅色表头、稳定列宽，尽量无斑马条纹。选中行淡蓝。操作列文字/图标保持一致。归属表六列：资料项 / 当前值·状态 / 操作人 / 操作·来源 / 操作时间 / 查看。
- 字段：标签在上，输入高40px，值靠左。州用下拉，选项显示州缩写及灰色小号全名（TX + Texas），两个地址各自独立。
- 信息区：6px圆角、1px边框，无厚阴影、无40px巨型圆角。现有公户三列数据展示必须保留，不因通用设计技能擅改列数。
- 状态：标签含清楚文字和小圆点，颜色不能是唯一依据。客户状态和当前申请状态独立，完成客户仍可有后续待补件申请。
- 附件：仅显示文件名/数量/已上传/查看，不在普通档案塞驾照缩略图。点击查看才进入预览覆盖层；只有核对原图或专门预览中展示图片。
- 操作归因：统一称“操作人”，不是最后修改人。编辑头部的本次操作人与字段既有操作人不是一回事。失败/取消/无变化不覆盖原归因。
- 抽屉：右侧固定，宽度按资料密度600–880px，固定底部按钮，正文独立滚动。标题第一层，客户副标题与本次操作人下一层。不要把操作人挤到标题或放正文底部。
- 弹窗：居中白面板、细圆角，取消/确认对齐右侧或原图布局。未保存确认与底层抽屉分层清楚。
- 骨架：结构精确匹配目标列表，客户行无头像，禁止新增圆形头像占位。空态告诉用户真实可执行动作；搜索无结果先清空搜索再选客户。
- 错误态：明确当前已保存值仍在；未知结果不能画成确定失败。替换失败旧文件有效；删除各步骤分开，不冒充原子完成。

## 5. Layout Principles

统一左侧“业务工作台”品牌、顶栏面包屑与右上示例日期。完整档案导航保留客户业务/网站/资源/系统分组；客户列表紧凑导航沿用已有变体，不擅自增加/删除产品模块。

档案头从上到下：返回客户列表 → 姓名/C001/当前档案、客户完成状态、当前申请状态/申请负责人、更多 → 八页签：概览 / 个人资料 / 企业资料 / 银行资料 / 网站与邮箱 / 材料审核 / 网关申请 / 资料操作归属。不存在独立“材料”页签。

正文24–28px内边距；分组间16–24px；表单列间16px；避免遮挡、水平溢出及把重要按钮裁到画板外。长内容允许垂直滚动而不是缩小到不可读。新建档路线统一上传驾照→人工核对→建档结果，没有手工无证件入口。

54个参考图代表13个主屏参考、29个覆盖层参考、12个状态参考，不是54个产品路由。路由家族仅客户列表、档案详情、上传驾照、人工核对、建档结果；档案页签和覆盖层复用同一档案上下文。画板可以分别展示，不能改变产品信息架构。

## 6. Motion & Interaction

不添加永久跳动、闪烁、列表级联或无关装饰动画。只允许120–180ms的hover/focus/抽屉轻过渡。减少动态偏好关闭非必要动画。固定页脚、键盘可聚焦和清晰禁用是交互语义，不用动画替代业务反馈。

当前迁移以桌面参考为验收范围。需要小屏呈现时多栏堆叠、44px触控目标、正文至少14px，不增加新的业务或信息。不得把未实际验证的响应式、按钮跳转、权限或远端接口宣称已实现。

## 7. Anti-Patterns / Never Do

禁止营销Hero、霓虹紫蓝、虚构评分/进度、客户级负责人、无驾照手工建档、独立材料页、材料打包导出、客户门户、自动推荐下一步、深度AI评分、测试付款业务、假装自动向支付平台提交、假装当前档案已同步线上网站。

禁止凭空增加删除权限、改派权限、同平台重新申请规则、补充定稿版本管理。只用DEMO数据：Alex Morgan/C001/Northline LLC/northline.example，不上传真实SSN或驾照。

首个有效获批完成客户；后续申请独立记录；一客户最多一个在办。AI审核只是参考，不通过也可人工知悉后申请。当前资料修改不回写既有申请定稿。页面内不得展示“落点待确认”等设计过程文字，未决事项单独记在BUSINESS.md。
