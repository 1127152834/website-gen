## 设计边界与核对

- 只显示已存字段、文件数量、已记录状态；不猜测下一步、具体缺件或平台要求。
- 客户完成与当前网关申请分开；已完成客户允许有后续申请。
- 文件数量和字段已录入不表示齐全、有效或通过审核。空值使用中性显示。
- 不把 AI 检查设置为申请门槛；本轮没有 AI 决策面板。
- 第一张偏向字段总表；第二张偏向材料存量；第三张偏向客户列表和选中记录速览。
- 现有源码样式与旧图仅用于视觉参考，不代表客户管理已实现。
- 本轮仅进行静态视觉与业务语义核对，不包含运行时、真实材料、OCR 或邮件 AI 验收。
- 图中控件是拟议交互，细节在选稿后确定。例如空邮箱不应出现可用的复制按钮，材料筛选需进一步明确范围。
