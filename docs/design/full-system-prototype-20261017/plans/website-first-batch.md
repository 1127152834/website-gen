# 网站任务与站点：首批绘制说明

这批先把已确认建站向导的后续路径接通。每张单独出图，继续使用既有应用壳和深藏蓝配色，不设计新的核心建站能力。

| ID | 职责 | 主要内容与动作 |
| --- | --- | --- |
| W01 | 建站总览 | 只展示已有任务、网站和实际异常；进入批次/站点，主按钮新建网站。不生成客户下一步建议。 |
| W05 | 批次列表 | 一次发起对应一个批次；客户数、进行中/等待/失败/建成数量、发起操作人和时间；打开详情。 |
| W06 | 批次详情 | 每客户/网站一行，区分建站中、等待外部服务、失败；展示当前步骤、最后记录、站点详情和失败重试入口。 |
| W07 | 网站列表 | 客户、企业/品牌、域名、建站状态、上线状态分开，按事实搜索筛选，进入详情。 |
| W08 | 网站详情概况 | 固定客户/企业/域名，步骤和日志分层；当前状态决定重试/上线是否出现。 |
