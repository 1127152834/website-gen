# 其他模块关键独立状态队列

来源：`prompts/other-modules-scenes.json` 的 `required_states`。  
数量上限：本轮只保留 10 个真正需要独立构图的关键状态；普通加载、保存中、成功 toast、常规空表和重复网络失败不再逐页画。

| ID | Parent | 独立场景 | 为什么独立 |
|---|---|---|---|
| ES01 | M02 | 切换邮箱/文件夹时清空旧正文并加载新邮箱；复用 M01/M02 壳 | 防止跨客户内容闪现，是隐私边界 |
| ES02 | M04 | SMTP 结果未知或已接受但副本未核对，锁定重复发送；复用 M04＋O-M08 | 防重复发信，不能等同普通失败 |
| ES03 | M05 | 来源证据冲突，降级人工确认，保留原文和纠正入口；复用 M03 | 证明证据优先及人工纠正 |
| ES04 | O-M05 | 邮箱因客户/申请关联而禁止永久删除；复用 M01 | 防误删关键状态 |
| ES05 | R01 | Token 无效且旧同步快照标记过期；复用 R01 | 区分本地旧事实与远端未知 |
| ES06 | R04 | 资源放弃部分成功、部分失败、部分未执行；复用 R04 | 高风险恢复与重试边界 |
| ES07 | T01 | Grist 未配置空态；复用 A01；常规读取失败复用 A07 | 未配置不同于第三方跨源故障 |
| ES08 | S09 | `paused_audit` 安全暂停、人工追查和重新批准条件；复用 S09 | 邮件 AI 最关键停机状态 |
| ES09 | A03 | 首次登录强制改密，无返回应用入口；复用 A03 表单 | 身份安全和返回行为不同 |
| ES10 | O-A05 | 远端对象已删除，禁止覆盖保存；复用 O-A05 | 防止并发操作复活已删除对象 |

## 复用原则

- 通用 403/404/500 分别复用 A05/A06/A07，不为每个模块重画。
- 通用未保存离开复用 O-A04；只有保存失败仍需保留输入时才在对应编辑器补局部状态。
- 常规加载、空表、搜索无结果、单次网络失败优先复用现有页面骨架和反馈组件，不进入本队列。
- 本队列只定义静态审阅画面，不证明真实重试、权限、并发控制、删除阻止或外部服务行为已经实现。
