# 新员工文档审计：02 网站建设与 04 邮箱

日期：10/18/2026（America/Los_Angeles）  
范围：仅审阅并修正 `一期原型-模块阅读版/02-网站建设与站点管理/模块介绍.md` 与 `04-邮箱与邮件跟进/模块介绍.md`。页面目录经核对无需修改；未修改 PNG、映射、应用代码或真实外部服务。

## 审计结论

两份原文的业务边界总体正确，但新人仍需要自行猜入口、按钮和完成标志。修订把关键 PNG 上实际可见的导航、三步顺序、阻塞状态、核验入口、工作区页签和交接信息写成可执行阅读路径。所有结论仅说明静态原型可见内容，不证明交互或服务已经实现。

## 静态 UI 缺口与边界

- 邮箱图片显示未读数、监听和工作页签，但没有独立通知中心画面；因此文档只说明通知是提醒，不编造清除、归档或跳转流程。
- 邮箱凭据弹窗有“进入密码重置”入口，目录只展示“显示已保存密码确认”，没有完整密码重置画面；文档不声称重置已执行。
- 邮件撰写、回复、回复全部和转发共用同类窗口，本目录的独立图片展示回复场景；文档不虚构未画出的差异步骤。
- 静态图不能证明按钮可点击、外部资源可读、邮件送达、模型准确、网站生成或上线实际成功。
