## 未解决的原型边界

- 账号接入和删除接入记录没有独立成功结果图；文档只能要求返回列表核对，不能描述具体成功提示。
- `05-账号与域名资源/03-资源管理-查看所选账号的域名.png` 的文件名强调“所选账号的域名”，画面主标题却是“域名详情”；按要求未改文件名或映射。
- 表格模块没有具体的连接失败、第三方权限错误或登录失败图，不能给出对应错误文案和恢复结果。
- 模型、CJ、Grist 当前图片分别停在未验证、尚未验证、未执行连接测试状态，没有正向成功结果图；真实可用性仍待实现和运行验证。
- 邮件 AI 的配置、授权、暂停与重新批准都是静态设计状态，不能据此声称正文已外发、模型已处理或批准已生效。
