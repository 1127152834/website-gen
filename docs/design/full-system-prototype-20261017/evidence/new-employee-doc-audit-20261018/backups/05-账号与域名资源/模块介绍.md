# 账号与域名资源

> **原型说明：**本目录展示的是静态界面图片，图片中的按钮、列表和输入框都不可点击，也不代表相关功能已经上线或已连接真实服务。

**一句话用途：**集中查看团队接入的 Hostinger 账号、域名及其网站和邮箱占用关系，并在明确影响后处理高风险的资源清理。

## 它在项目中的位置

这个模块是内部业务工作台的“资源底座”。客户档案说明服务对象，建站模块记录网站工作，邮箱模块处理通信；这里负责说明这些网站、域名和邮箱落在哪个已接入账号下，以及最近一次成功核对时看到的状态。接入账号或管理域名，并不会自动申请公司、购买服务，也不代表任何平台或支付网关已经批准。

代表页面：[查看账号与域名总览](01-资源管理-账号与域名总览.png)

## 谁在什么时候使用

- 负责账号接入的内部同事，在首次接入或添加新的 Hostinger 接入账号时，填写连接所需的账号名称和授权信息。
- 负责网站、邮箱或域名维护的内部员工，在排查资源归属、到期信息或关联关系时查看。
- 只有在确认不再保留某项站点或域名资源时，才进入“放弃资源”流程；关联邮箱可能属于其中需要确认的影响范围，不是本模块单独的放弃入口。客户本人不登录本系统。

## 常用流程

1. **接入账号：**选择“添加账号”，填写便于团队识别的名称和连接所需的授权信息，再发起验证。保存了信息不等于验证成功，应以页面返回的验证结果为准。
2. **核对资源：**选中账号并同步，查看域名、网站、邮箱数量及最近同步时间；再进入某个域名的详情，核对它关联的网站、邮箱和客户。
3. **判断信息是否新鲜：**旧的同步快照只能说明过去一次成功读取到什么，不能证明远端当前状态。验证或读取失败时，页面应显示“未知”或失败原因，不能据此推断账号被封、域名失效。
4. **处理危险操作：**删除账号接入记录、放弃网站或域名资源、删除客户是三件影响范围不同的事。操作前先读确认说明和关联影响；放弃资源时需确认具体域名，并逐步查看已完成、失败和未执行的步骤。
5. **处理部分失败：**已成功的远端步骤可能无法撤销。只重试失败步骤，或取消尚未执行的部分；不要把部分完成写成整体成功，也不要假设系统会自动恢复。

## 一个虚构用户故事

内部员工林悦准备整理一个演示站点。她先在账号列表中选择演示账号并同步，再打开域名详情，发现域名仍关联一个网站和商业邮箱。她没有直接放弃资源，而是先核对关联。后来团队确认使用的是另一条无客户关联的演示资源，她输入目标域名开始清理：本地关联记录已清除，但远端邮箱移除失败，释放域名尚未执行。林悦只重试失败的邮箱步骤，并把未执行部分保留到下次处理，没有把这次操作登记为“全部完成”。

## 常见误区与异常处理

- **误区：账号显示正常，就代表远端现在正常。**这里只可能是快照；先看同步时间，必要时重新验证。
- **误区：删除接入账号就是删除远端资源。**删除接入记录主要影响本系统中的授权信息和同步快照，不能当成远端网站、域名或邮箱已删除。
- **误区：资源清理等于删除客户。**资源清理只处理选定的网站、邮箱或域名步骤；客户资料和网关申请有各自独立的处理规则。
- **异常：验证失败或信息过期。**保留现有事实，标为未知并重试；不要自行补出原因。
- **异常：执行结果混合。**逐项记录成功、失败、未执行和操作人；远端已发生的变更不承诺自动回滚。
