# 登录与全局工具

> **原型说明：**本目录展示的是静态界面图片，图片中的登录、导航、搜索、助手和异常处理控件都不可点击，也不代表这些功能已经上线或通过真实交互验证。

**一句话用途：**为内部用户提供登录、改密、统一导航、搜索、AI 助手以及未保存、并发冲突和访问异常的安全处理入口。

## 它在项目中的位置

这一组页面是内部业务工作台的公共外壳，不是新业务流程。目录中的通用导航图借“上传驾照建档”页演示应用壳，**不代表又增加了一套建档页面**。网站生成、网站上线和网关批准仍是不同事实；全局工具不提供付款测试或后续代运营。

## 谁在什么时候使用

- 获授权的内部员工用账号密码登录；客户没有登录入口。
- 首次登录或密码重置后先完成强制改密；日常可从个人菜单改密、切换主题或退出。
- 员工需要快速找页面、客户、站点或设置分区时使用全局搜索；需要查询或导航帮助时打开 AI 助手。
- 编辑尚未保存、同事同时修改、会话或服务异常时，按相应保护页面处理。

## 常用流程

1. **登录与改密：**输入内部用户名和密码。首次改密必须成功后才能进入业务页；主动改密可从个人菜单进入。内部密码与客户商业邮箱密码不同。
2. **使用统一导航：**从侧栏切换模块，窄屏时先开菜单。搜索结果只用于导航，打开页面后仍要核对最新数据和权限。
3. **使用 AI 助手：**可询问当前页面或本地数据摘要。涉及写入等有副作用的工具时，确认卡必须显示动作、对象和参数；确认前不得执行，建议也不等于操作已经完成。
4. **开始新对话：**新对话只清空对话上下文，不会撤销已经执行的操作；尚待确认的工具也不能被静默执行。
5. **保护编辑：**未保存就离开时，选择继续编辑或明确放弃。别人已修改时先比较或重新读取；记录已删除时不覆盖，也不自动重建。
6. **处理异常：**会话失效后重新登录，未提交内容可能需重填，系统不自动重放敏感操作。身份复核暂时失败不等于会话失效，可重试或返回登录。无权限、不存在和服务异常也应分别处理。

## 一个虚构用户故事

员工周岚首次登录并修改初始密码，再从窄屏菜单进入业务页。AI 助手只给出某邮箱的本地摘要和导航入口；准备修改记录时先展示确认卡。编辑资料时，同事刚更新了地址，周岚选择比较并重新读取。稍后会话失效，她重新登录并重填未提交内容，没有假设系统已自动保存或重放。

## 常见误区与异常处理

- **误区：助手说“可以处理”就代表已经执行。**只有明确确认并收到实际结果后，才可判断工具操作是否完成。
- **误区：离开页面会自动保存。**出现未保存提示时，应继续编辑或明确放弃。
- **误区：冲突时用本地内容覆盖即可。**先比较最新内容；对象若已删除，应退出或重新读取，不能覆盖重建。
- **异常：会话失效。**重新登录，不承诺恢复输入，也不自动重放发送、删除、授权等敏感动作。
- **异常：身份复核暂时失败。**保护业务数据，允许重试或返回登录；不要把它与确定失效混为一谈。
- **异常：无权限、页面不存在或服务不可用。**分别返回可访问位置、核对链接或稍后重试，不用空页面伪装成功。
