# 表格协作

> **原型说明：**本目录展示的是静态界面图片，图片中的按钮、表格和登录入口都不可点击，也不代表相关功能已经上线或已连接真实 Grist 服务。

**一句话用途：**在内部工作台中打开第三方 Grist 原生工作区，让团队使用 Grist 自己的文档、页面和表格能力进行协作。

## 它在项目中的位置

这个模块是业务工作台通往外部协作表格的入口。工作台只提供配置状态、登录、刷新、设置和新标签打开等外壳；真正的文档、页面、组件、单元格编辑和权限由 Grist 原生区域承担。它不是系统自建的表格编辑器，也不是客户资料导入流程，更不表示客户可以登录系统。

代表页面：[查看 Grist 原生文档与表格](02-表格工作区-Grist原生文档与表格.png)

## 谁在什么时候使用

- 已获准访问团队协作数据的内部员工，在整理业务清单、共享记录或使用既有 Grist 文档时进入。
- 负责 Grist 配置的内部同事，在首次使用前到系统设置中填写服务地址和连接所需的授权信息，并单独测试连接。
- 遇到登录、加载或权限问题时，员工先分清问题发生在工作台外壳、连接配置，还是 Grist 原生页面中。

## 常用流程

1. **确认是否已配置：**打开“表格”后先看配置状态。若明确显示“尚未配置”，前往设置补充服务地址和授权信息；这与“已经配置但连接失败”不是同一种情况。
2. **完成第三方登录：**配置存在但尚未登录时，使用“登录 Grist”入口。若弹窗被浏览器阻止，可按页面提示允许弹窗，或用新标签打开。
3. **使用原生工作区：**登录后，在标明“Grist 原生界面（第三方）”的区域内选择文档、页面和表格，并使用 Grist 自己提供的筛选、排序和编辑功能。
4. **刷新或切换窗口：**页面显示不完整时先刷新嵌入区域；需要更大空间或处理第三方登录时，在新标签中打开同一地址。
5. **处理故障：**工作台可以说明没有配置、读取配置失败或无法载入嵌入区域，但不保证能够看见或控制第三方页面内部的全部错误。遇到原生权限或文档问题，应按 Grist 页面实际提示处理。

## 一个虚构用户故事

内部员工周岚需要查看团队维护的网关跟进表。她从侧栏进入“表格”，页面显示服务已配置但尚未登录。完成 Grist 登录后，她在第三方原生区域打开共享文档并筛选待补件记录。一次刷新后嵌入区域仍为空，她改用“新标签打开”，看到 Grist 自己提示当前账号没有该文档权限，于是联系管理员调整第三方权限，而没有把问题误报成工作台丢失了客户资料。

## 常见误区与异常处理

- **误区：这里的表格由本系统创建和控制。**系统只是嵌入或跳转到 Grist；原生内容和编辑行为由第三方负责。
- **误区：这是客户批量导入入口。**一期原型没有客户表格导入流程，不能用此页面代替客户建档。
- **误区：保存连接信息就代表能正常访问。**保存与连接测试是两步；成功测试也不等于每个 Grist 文档都已授权。
- **异常：尚未配置。**前往 Grist 设置完成地址和授权信息，再返回表格入口。
- **异常：连接或加载失败。**可重试读取、刷新嵌入区域或新标签打开；不要根据宿主页面猜测第三方内部原因。
