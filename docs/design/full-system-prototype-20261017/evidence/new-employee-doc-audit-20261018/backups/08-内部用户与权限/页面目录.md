# 内部用户与权限：页面目录

[先读模块介绍](模块介绍.md) · [返回全系统阅读指南](../README.md)

管理工作人员的系统登录账户。内部用户不是你们服务的美国客户，也不是客户的商业邮箱。

本目录共 **4 张图片**，按理解和使用顺序排列。点击名称打开图片，也可以在文件夹中按编号浏览。图片是静态设计示例，不能点击其中的按钮。

**不需要逐张完成所有操作。** 正常业务只走需要的页面；失败、空白、冲突等画面是在对应情况下出现的备选状态。弹窗和侧边展开区不是新的业务阶段。
