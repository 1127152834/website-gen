## 必须修正

### F01：W09 空输入仍显示可“发送并执行”

- 位置：页面底部输入框右侧。
- 现象：输入框仅有占位文字“描述要修改的网站内容...”，当前无执行中的任务，但“发送并执行”为深蓝启用样式。
- 影响：静态界面暗示空请求可启动有副作用的网站操作，与必要的输入校验不一致。
- 最小修正：**仅将空输入下的“发送并执行”按钮改为明确禁用样式**。不补虚构输入，不修改已成功对话、CHG-014、时间或状态，也不增加停止按钮。
- 修正后需要再次查看图片；截图仍不能证明实际组件已经禁用。

### F02：W10 SPF说明保证性过强

- 位置：DNS配置表，SPF行说明列。
- 现象：当前文案“防止发信被判定为垃圾邮件”暗示配置SPF即可避免垃圾邮件判定。
- 影响：把配置检查与最终投递/分类结果混同。
- 最小修正建议：改为 **“声明允许发信的服务器，不保证送达。”** 或简洁等义表达。不改“已配置”状态、不假称实际投递已测试。
- 同一次局部文案修正可顺带把DKIM“用于邮件签名，提升送达率”换成更准确的“用于邮件签名与完整性验证”；此项不是独立布局阻断，不必重画整个表格。
- 底部“测试邮件仅验证发信，不代表订单支付或网关获批”当前正确，保留。
