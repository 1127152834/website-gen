# 账号与域名资源

> **原型说明：**本目录展示的是静态界面图片，图片中的按钮、列表和输入框都不可点击，也不代表相关功能已经上线或已连接真实服务。

**一句话用途：**集中查看团队接入的 Hostinger 账号、域名及其网站和邮箱占用关系，并在明确影响后处理高风险的资源清理。

## 它在项目中的位置

这个模块是内部业务工作台的“资源底座”。客户档案说明服务对象，建站模块记录网站工作，邮箱模块处理通信；这里负责说明这些网站、域名和邮箱落在哪个已接入账号下，以及最近一次成功核对时看到的状态。接入账号或管理域名，并不会自动申请公司、购买服务，也不代表任何平台或支付网关已经批准。

代表页面：[查看账号与域名总览](01-资源管理-账号与域名总览.png)

## 谁在什么时候使用

- 负责账号接入的内部同事，在首次接入或添加新的 Hostinger 接入账号时，填写账号名称和 API Token。API Token 是从 Hostinger 控制台生成的连接凭据，不是员工的登录密码。
- 负责网站、邮箱或域名维护的内部员工，在排查资源归属、到期信息或关联关系时查看。
- 只有在确认不再保留某项站点或域名资源时，才进入“放弃资源”流程；关联邮箱可能属于其中需要确认的影响范围，不是本模块单独的放弃入口。客户本人不登录本系统。

## 开始前准备

- 接入账号时，准备团队易懂的账号名称和对应 Hostinger API Token。
- 查资源时，先知道要核对哪个账号或域名；页面展示的是最近一次同步快照，不是实时保证。
- 放弃资源前，准备准确域名，并先核对客户、网站和邮箱关联。只要仍关联客户，图中流程会显示“本次不执行放弃”。

## 新人任务导航

| 要做什么 | 从哪里开始 | 关键动作 | 看到什么才算走到下一步 |
|---|---|---|---|
| 接入 Hostinger 账号 | 左侧“账号与域名” → “添加账号” | 填账号名称和 API Token，选择“验证并添加” | 返回接入账号列表后，应能看到该账号及明确的验证、同步状态；本组静态图没有单独的成功提示页，不能只凭按钮已按下判断成功 |
| 查看域名占用 | 在接入账号列表选择账号并“同步”，再查看账号域名区域 | 打开目标域名，核对到期日、网站、邮箱、客户和同步时间 | 信息来源和最后核对时间清楚后，再进入站点、邮箱或客户页面处理对应业务 |
| 删除本地接入记录 | 账号行的“删除接入记录” | 阅读影响后“确认删除” | 图中确认框说明只删除本地 Token、快照和本地关联，远端账号、网站、域名、邮箱不会被删除；静态图未展示删除结果页 |
| 放弃站点或域名资源 | 域名页面的“发起既有放弃操作” | 先核对影响清单，再按提示输入完整域名 | 有客户关联时停止并返回客户档案核对；允许执行时，以结果页的“已完成、失败、未执行”逐项判断，不能把部分成功当成全部完成 |

若 Token 验证失败，使用“更新 Token”或“重新验证”。黄色“上次同步快照（已过期）”只能用于核对旧信息；恢复验证并重新同步前，不据此判断远端现状。放弃流程部分失败时，只重试失败步骤，或取消尚未执行的部分；已经完成的远端变更可能无法撤销。

## 一个虚构用户故事

按原型中的演示情境，林悦打开目标域名后先看到网站、邮箱和客户关联，因此“放弃”被阻止，她应先回客户档案核对关系。另一张结果图展示了不同的无客户关联资源：本地关联清理已完成、移除邮箱失败、释放域名未执行。若系统将来按此设计实现，林悦应只重试失败步骤或取消未执行部分，不能把画面理解成已经全部清理成功。

## 常见误区与异常处理

- **误区：账号显示正常，就代表远端现在正常。**这里只可能是快照；先看同步时间，必要时重新验证。
- **误区：删除接入账号就是删除远端资源。**删除接入记录主要影响本系统中的授权信息和同步快照，不能当成远端网站、域名或邮箱已删除。
- **误区：资源清理等于删除客户。**资源清理只处理选定的网站、邮箱或域名步骤；客户资料和网关申请有各自独立的处理规则。
- **异常：验证失败或信息过期。**保留现有事实，标为未知并重试；不要自行补出原因。
- **异常：执行结果混合。**逐项记录成功、失败、未执行和操作人；远端已发生的变更不承诺自动回滚。
