# 表格协作：页面目录

[先读模块介绍](模块介绍.md) · [返回全系统阅读指南](../README.md)

在系统的入口中打开第三方 Grist 表格。这里不是客户建档导入入口，也不是另做一套表格编辑器。

本目录共 **3 张图片**，编号沿用页面映射，并不是每次都要按 01→02→03 操作。未配置时先看 03 并去系统设置；已配置未登录时看 01；登录后的目标状态看 02。点击名称打开图片，也可以在文件夹中按编号浏览。图片是静态设计示例，不能点击其中的按钮。

**不需要逐张完成所有操作。** 正常业务只走需要的页面；失败、空白、冲突等画面是在对应情况下出现的备选状态。弹窗和侧边展开区不是新的业务阶段。

| 顺序 | 页面与功能（点击看图） | 画面形式 |
|---|---|---|
| 01 | [表格工作区-打开第三方表格入口](01-表格工作区-打开第三方表格入口.png) | 工作页面 |
| 02 | [表格工作区-Grist原生文档与表格](02-表格工作区-Grist原生文档与表格.png) | 第三方原生界面 |
| 03 | [表格工作区-尚未配置连接](03-表格工作区-尚未配置连接.png) | 关键状态示例 |
