## 1. 本张图负责什么

这是新建网站三步向导的第二步，不是站点列表或建站结果。第一步选客户、核对企业与经营资料；本步逐客户配置；下一步确认启动。一个客户、一家企业、一个网站，单客户和多客户使用同一套结构。

文件：`W03-site-configuration-v1.png`，1489 × 1056 PNG。

仅绘制一张静态原型，无 HTML/React/业务代码，无实际网站、邮箱或域名操作。

## 2. 示例与业务约束

- 本张使用 Jamie Chen / Cedar Living LLC、Taylor Brooks / Paperfield LLC、Jordan Lee / Harbor Supply LLC 三位虚构客户。示例前提是他们尚无网站，企业资料与 EIN 已在上一步核对。
- 没有使用已有 Northline 网站的 Alex Morgan，避免在连续原型中表现为给同一家企业再次建站。
- 每行固定展示客户及企业、域名、商业邮箱、店铺品牌、商品品类和配置状态。每条记录各自使用对应域名下的商业邮箱，不共享另一客户的企业或邮箱。
- 只展开 Jamie 的详细参数。商品数量、可选售价区间以及上一步的处理/运输时效均仅属于 Jamie。不是把同一套企业信息应用给整批客户。
- “已填写”只描述本张图中的配置填写状态，不代表真实资源验证、建站成功、已上线或网关获批。
- 当前页为步骤 2，按钮为“上一步”和“下一步：确认启动”；下一步只导航，最终确认后才提交。
- 展示“操作人”，不引入固定客户负责人。图上“提交成功后记录”指本次建站提交的归属，不改动客户资料现有操作人。
- 页面日期使用 MM/DD/YYYY。

## 3. 控件设计意图（静态图未实现）

| 控件 | 设计行为与边界 |
| --- | --- |
| 域名 | 从可用资源中选择；缺失、占用、冲突、读取失败等状态后续分别绘制，不在本张假装验证成功 |
| 商业邮箱 | 选择当前客户对应域名下已开通的邮箱；现有单邮箱自动选择、多邮箱手选规则保留；示例不代表 SMTP 已启用 |
| 店铺品牌 | 可与企业法定名称不同，独立配置 |
| 商品品类 | 可搜索候选项，也允许输入更细分品类，例如圆珠笔、男士背心；不是仅限图中三个大类 |
| 展开 / 收起 | 在当前客户行下展示或隐藏详细参数，不切换客户归属、不创建第二个网站 |
| 商品数量 | 沿用当前 1–200 范围；输入与错误提示仍需后续交互实现与验证 |
| 售价区间 | 可选、USD；最小值不能大于最大值，错误提示后续补图 |
| 订单处理 / 运输时效 | 展示来自上一步的工作日范围；如需修改，返回上一步调整该客户，不在整批共享 |
| 移出 | 仅移出本次未提交建站项，不删除客户、企业、材料或网站；确认提示后续单独绘制 |
| 上一步 / 下一步 | 保留当前未提交配置；最终提交、调用外部服务及成本确认放在下一步，不提前发生 |

单客户时保留相同列与展开区，仅显示一行，底部计数为“1 位客户 · 1 个网站”。这属于设计约束，本次未额外绘制单客户状态。
