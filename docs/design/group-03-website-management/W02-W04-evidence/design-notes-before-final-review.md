# 三步建站向导：补充 W02 与 W04

日期：10/17/2026。范围：补画第一步「客户与经营资料」与第三步「确认启动」。第二步 W03 原图保持不变。

本轮为原型图片设计，不写应用代码、不操作真实客户资料，不调用 Hostinger/CJ/邮件等业务服务，不启动真实建站。

## 1. 三个步骤分别负责什么

| 步骤 | 内容 | 主操作 | 是否提交建站 |
| --- | --- | --- | --- |
| W02 客户与经营资料 | 选择已有客户，核对各自企业资料，分别填写处理与运输时效 | 下一步：站点配置 | 否 |
| W03 站点配置 | 每客户一行配置自己的域名、商业邮箱、品牌、品类与商品参数 | 下一步：确认启动 | 否 |
| W04 确认启动 | 按客户逐项复核最终输入，提示外部调用、费用与维护模式 | 确认并开始建站（3） | 点击确认后才提交；本图为点击前 |

单客户只展示一行，直接展开；多客户使用同一套流程。每家企业只对应一个网站，不保留整批共享企业表单，也不允许给同一企业再加一个网站。

## 2. W02：客户与经营资料

归档图片：`W02-customer-business-info-v1.png`。

- 通过「选择客户」加入已有客户，不建立无驾照的新客户；选过的客户不能重复加入。
- 三行各自显示客户及企业、企业资料/EIN 条件和网站关联情况。当前正常示例均为资料齐备且未关联网站。
- Jamie 展开显示企业法定名称、企业地址、网站联系电话、商业邮箱和 EIN 录入状态。来源字段只读，更正入口是「查看客户档案」，不另造一份可以随便填写的客户原始资料。
- 企业地址来自企业档案；网站联系电话取该客户个人电话；邮箱使用该客户商业邮箱，不取个人邮箱。
- EIN 只展示已录入，不作为网站公开字段；本页不展示 SSN、驾照、银行资料。
- 可编辑订单处理与运输时效，分别属于当前客户的建站项，不应用到所有客户。两项范围单位均为工作日。
- 「移出」只移出本次未提交项，不删除档案或实际网站；「取消」离开向导，存在未保存配置时复用未保存确认。
- 图中的「资料与 EIN 齐备」只描述演示前置条件，不表示已经读取真实服务、生成网站或获批网关。

## 3. W04：确认启动

计划归档图片：`W04-confirm-start-v1.png`。最终出图与核对结果以 README 和验证记录为准。

- 最终确认页沿用同一组客户、企业、域名、邮箱、品牌和品类；只读核对，不混用整批公共经营资料。
- 展开某客户查看该客户企业地址、联系电话、商品数量、售价、处理和运输时效。分别提供「修改经营资料」「修改站点配置」入口，回到对应步骤和客户，保留其他配置。
- 三步保持「操作人：李敏 · 提交成功后记录」，不引入固定客户负责人；提交归属不覆盖客户档案字段原有操作人。
- 明确告知将调用 Hostinger 创建网站、读取 CJ 商品、调用模型生成内容，可能产生模型费用；不编造具体费用。
- 生成后仍保持维护模式，需人工检查并上线；建站完成不代表支付网关获批或客户完成。
- 知悉说明的勾选是正常提交前状态，不等于任务已经提交；只有明确的「确认并开始建站」动作才发起提交。
- 未就绪项、资源冲突或读取失败应定位到具体客户，返回修正或明确移出，不能静默跳过；提交结果未知时先核验记录，不盲目再次创建。这些异常状态后续分别补图，本轮不宣称已画齐。
