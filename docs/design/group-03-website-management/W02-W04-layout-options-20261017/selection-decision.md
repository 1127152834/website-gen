## 多客户展示规则（后续细化的设计约束）

1. **三条是示例，不是数量限制。** 页面显示实际已选客户数 N；每个客户对应一个企业及一个网站。不在本轮凭原型图新增业务上限，也不承诺无限批次容量。
2. **W02 工作表纵向延伸。** 客户增多时让表格区域滚动，表头与底部“下一步”保持可访问。资料摘要只对应当前查看的客户，不随所有客户重复展开；切换查看或滚动不能清空其他客户已填的时效。
3. **W04 左侧清单独立纵向滚动，右侧全局确认区保持可见。** 不因客户增多继续新增横向客户列，不缩小文字强塞一屏。右栏统一显示 N 位客户、N 个网站、操作人、启动说明、确认框与启动按钮。
4. **可见范围不等于提交范围。** 启动按钮的 N 指全部已选建站项，不是当前视口中的几条；核对和提交校验覆盖整个批次。切换页面/滚动不改变已选集合。
5. **不伪造核对进度。** 不因某客户滚入视口就认定人工已核对；保留全局人工确认，不自动生成“全部已核对”事实。未选确认框的状态及其他异常仍待后续绘制。

上述是设计规则，不是运行效果证明。长列表滚动、较小窗口下资料区与操作区的可达性、真实批次容量与异常定位均待后续原型/实现验证；本次没有新增多客户状态图。
