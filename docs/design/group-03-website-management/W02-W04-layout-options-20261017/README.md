## 不变的业务边界

- 一客户、一企业、一网站。可单客或多客建站，不能套用共享企业模板。
- W02：选择已有客户；企业资料与 EIN 齐备、未关联网站；档案来源只读，按客户填写订单处理与运输时效。此步只进入配置，不提交建站。
- W04：只读核对；可返回修改；确认后一次启动本批 3 位客户。图片仍处于尚未提交状态，不表示网站已生成。
- 企业名称和企业地址来自企业档案，网站电话来自客户个人电话，商业邮箱属于该客户。店铺品牌可与企业名称不同。
- 外部调用可能产生费用；网站生成后保持维护模式，人工检查后上线；建站完成不等于网关获批。
- 日期采用 MM/DD/YYYY，操作人用“李敏”；无客户固定负责人字段。
- [演示数据](demo-data.json)全部为虚构。Taylor/Jordan 的详细地址、电话、数量与时效为本次跨方案对照补齐，不是对真实客户档案的修改。
