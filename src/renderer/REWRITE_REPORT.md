## Reference reuse

Studied and adapted the checked-out reference's AppSidebar, NavGroup, NavUser/ProfileDropdown, Header/TopNav, AuthenticatedLayout/Main, Search/CommandMenu, ThemeSwitch, SkipToMain, ConfirmDialog, PasswordInput, data-table toolbar/column-header/faceted-filter/pagination/view-options patterns, feature forms, route/error boundaries, context/hooks and theme tokens.

The sidebar/sheet, command, dropdown, tooltip, table, button, card, dialog, input, select and supporting UI primitives were copied/adapted. Individual Radix imports were changed to installed `radix-ui` umbrella exports; reference Radix icon imports were replaced with Lucide where needed. The existing `cn` package supplies class merging. The full MIT notice is retained and emitted as `THIRD_PARTY_NOTICES.txt` into production builds; the bundled notice hash matches the source notice.

Clerk, axios, faker, demo tasks/apps/chats/help-center, devtools, RTL/direction and font-switcher settings were not introduced. The installed self-hosted Geist font with Chinese fallbacks is used instead of adding Inter/Manrope dependencies. No missing package was needed.

## Data and routing evidence

- RPC method names are unchanged: AST inventory found **84 baseline methods and 84 migrated methods**, **0 missing / 0 added**. Call-site payload shapes are recorded in `.migration/rpc-inventory.json`; the batch payload has an exact conversion test. This is source/local-test evidence, not live remote-service acceptance.
- Query keys include identity, resource, method and canonical params. Existing `useRpcData` consumers now use TanStack Query, retaining stale data during revalidation and exposing errors/retry without a second cache implementation.
- SSE stays in `lib/backend.ts`, including sequence/replay/reconnect logic. Changed topics, run events, settled chat/assistant streams and mailbox pushes invalidate appropriate Query resources. Streaming deltas still update transient local text/log state; active QA polling remains a fallback, not a replacement transport.
- Session switches clear caches and pending confirmations; focus revalidation freezes requests/interactions and preserves same-user drafts/cache. Late identity responses and queued RPCs cannot cross a logout/user switch.
- File routes cover `/`, `/new`, batch details, site base/five tabs, `/accounts`, mailbox/folder/message deep links including encoded folder names, `/tables`, `/settings`, `/users`, login/password and Chinese 403/404/500 pages. Generated-tree runtime tests exercise guards and malformed IDs, not merely a standalone URL parser.

## Intentional changes / omissions

- No business feature or RPC method was intentionally dropped.
- Removed old shell/theme CSS, hand-written router, bespoke RPC cache and unused compatibility page wrappers. The decorative animated assistant mascot became a neutral Lucide assistant button; assistant behavior remains.
- Tables for batch/site/account/domain/user resources use TanStack Table. Mail retains its specialized server-paginated reading list and Grist retains its typed editable grid instead of forcing those interactions into the generic client-paginated DataTable.
- Voluntary password change has a bookmarkable `/change-password` screen instead of the old header modal. Existing Chinese smoke-test accessible names remain stable, so `scripts/smoke.ts` did not require selector changes.
- Vite disables dotenv loading, places router temporary files inside the permitted renderer tree, enables file-route splitting and bundles the MIT notice. No server deployment was performed.
